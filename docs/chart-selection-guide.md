# 图表选择指南

先写出读者必须回答的问题，再选择图形。

| 读者问题 | 首选 | 需要升级时 | 避免 |
|---|---|---|---|
| 随时间怎样变化 | 折线图 | 小多图、区间带、事件带 | 只有两点却画连续趋势 |
| 谁高谁低 | 排序条形图 | 点图、棒棒糖图、坡度图 | 每个类别任意换色 |
| 高于或低于基准多少 | 发散条形图 | 差值点图、盈余／赤字图 | 隐藏零线或基准 |
| 绝对规模相差多少 | 柱形图／条形图 | 比例符号、小多图 | 柱图截断零基线 |
| 数值怎样分布 | 直方图 | 箱线图、小提琴图、点阵 | 把连续箱当离散类别 |
| 两个指标是否相关 | 散点图 | 分面散点、密度图 | 用连线暗示不存在的时间顺序 |
| 各部分占整体多少 | 100%堆叠条 | 矩形树图、少扇区饼图 | 扇区过多、分母不明 |
| 数量怎样流动／连接 | 桑基图／网络图 | 弧线图、流向图 | 线宽与数值无关 |
| 地理位置在哪里 | 真实投影地图 | 分级设色、点地图 | 把任意气泡布局称为地图 |

## 发布前六问

1. 图形回答的是读者真正的问题吗？
2. 时间、单位、分母、样本量或适用范围是否明确？
3. 同类图表的尺度是否一致？
4. 去掉颜色后，重点和系列是否仍能辨认？
5. 390px宽度下，标题、标签、数值和来源是否可读？
6. 装饰是否侵入数据区或改变几何比例？
