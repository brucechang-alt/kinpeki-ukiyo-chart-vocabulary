# 新摺高彩 · 色彩使用规范

原作参考图保持博物馆图像原貌；以下色值用于当代图表重建，不是历史颜料的科学测量或复原。

## 角色固定

- 胡粉纸 `#fbf3de`：页面和绘图区。
- 墨 `#181a1b`：标题、正文、坐标、主版线和参考线。
- 普蓝 `#0069a6`：默认数据、单序列和时间趋势；小字用深普蓝`#004b7a`。
- 鲜朱 `#e24832`：焦点标记、异常、风险和必须解释的转折；小字用深朱`#b83326`。
- 緑青 `#3a8a5c`：第二序列或有明确语义的正向状态；小字用深緑青`#2f6d49`。
- 明黄 `#e2a228`、藤紫 `#8d4b8e`：只有类别身份确实重要时才加入；对应小字用`#905d0b`、`#713c73`。
- 亮金 `#e0b53a`：分扇、标题和小面积结构提示，不进入连续量值色阶；小字用深金`#81620b`。
- 薄墨线 `#c8b990`：网格和次要分隔。

## 三档配色

### 单根色

单序列趋势、排名、分布和多数散点图，只使用普蓝、墨和胡粉纸。重点点可使用鲜朱。

### 两根色上限

二元比较、正负偏差、焦点对背景、基准对实际，最多两个非中性色。系列还必须同步改变实虚线、空实心或直接标签。

### 五根色放宽

只有互斥类别身份是问题本身时，才使用普蓝、鲜朱、緑青、明黄、藤紫五色。超过五类时使用小多图、前N项＋其他或改变图形。

## 禁止

- 不用红绿作为唯一的正负编码。
- 不在数据标记内部使用渐变。
- 不使用自动彩虹色板。
- 不用金色表示“数值较大”，除非金色本身有明确分类含义。
- 不把纹理、套版错位或纸张噪点放进数据标记内部。
