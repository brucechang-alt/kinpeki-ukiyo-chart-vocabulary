# 风格转译说明

## 两个传统，各自承担什么

狩野派与浮世绘不是同一个历史流派。本系统只把两者的不同视觉特征转译为现代图表规则。

| 艺术特征 | 图表转译 | 不允许的误用 |
|---|---|---|
| 金碧屏风分扇 | 页面区块、阅读节奏、章节缝 | 金色铺满绘图区 |
| 墨线骨架 | 坐标、主版线、关键边界 | 用粗线改变面积或线宽数据 |
| 大型自然母题 | 页眉和绘图区外的结构剪影 | 松、浪、云覆盖数据点 |
| 浮世绘主版线 | 填充标记统一保留墨色轮廓 | 套版错位移动数据位置 |
| 平涂套色 | 显式、有限、职责固定的色板 | 自动渐变和彩虹色 |
| 斜向切入和高视点 | 海报布局、标题裁切和分区 | 倾斜坐标轴或扭曲地图 |
| ぼかし | 离散色阶、不确定性区间 | 在柱、点、饼扇区内做装饰渐变 |

## 字体

- 标题：Source Han Serif SC／Noto Serif CJK SC，日文环境可退回Yu Mincho。
- 正文、坐标和数值：Source Han Sans SC／Noto Sans CJK SC。
- 日文竖排只用于短签和装饰，不用于单位、来源和关键数字。

## 线条

- 数据主线：2.5—3px。
- 墨色主版轮廓：0.65—1px。
- 坐标和基线：1px墨色。
- 网格：0.8px薄墨虚线。
- 朱色序列：长虚线；緑青序列：点线；朽葉序列：细点线。
