# 金碧浮世 · 图表词汇

一套面向新闻、研究、教学和商业分析的现代数据视觉系统。它以狩野派金碧屏风的空间秩序组织版面，以浮世绘套色木版的主版线、平涂色面和斜向构图组织图形，并以现代数据可视化规范约束尺度、单位、标签和可访问性。

> 这是一套当代融合设计，不宣称“狩野派浮世绘”是历史上存在的单一画派，也不代表任何博物馆或艺术机构的背书。

当前公开版采用“新摺高彩”规则：原作参考图保持博物馆图像原貌，图表色按新印木版的鲜明层次重新建立。高纯度色只用于数据标记；小号彩色文字使用同色相深阶色。这不是对历史颜料的科学复原。

## 包含内容

- 九类信息关系
- 中文、英文、日文各67个可独立编辑、下载和复用的SVG，共201个
- 三种语言各一张2400px宽的图表总表
- 三种语言各自独立的响应式浏览页和390px手机适配
- 葛饰北斋《神奈川冲浪里》完整原作参考区
- 色彩token、选图指南、用色规范和风格转译说明

## 三种语言

- 中文：`index.html`
- English: `index-en.html`
- 日本語：`index-ja.html`

三种版本共用相同的数值、尺度、图形几何和色彩token；图表名称、问题、坐标文字、图例、无障碍标题与说明均分别本地化。

## 使用原则

1. 先确定读者要比较的关系，再选择图形。
2. 单序列优先普蓝；鲜朱只用于重点、异常和风险。
3. 不用颜色单独编码。多序列同时使用线型、空实、轮廓、排序或直接标签。
4. 柱图从零起点；面积、长度、线宽、位置和角度不得被装饰改变。
5. 金色只用于分扇、标题和小面积结构提示，不铺满绘图区。

## 本地查看
