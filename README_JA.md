# 金碧浮世・チャート語彙

報道、調査、教育、ビジネス分析のための現代的なデータ可視化システムです。狩野派の金碧障壁画から画面構成の秩序を、浮世絵木版画から主版線、平面的な色面、斜めの動勢を取り入れ、尺度、単位、ラベル、アクセシビリティは現代の可視化規範で統制しています。

これは現代の融合デザインです。「狩野派浮世絵」という単一の歴史的流派を主張するものではなく、博物館や文化機関の承認・後援を示すものでもありません。

公開版は「新摺・高彩度」の規則を採用します。美術館の参照画像は改変せず、チャート色は摺り上がったばかりの版画を想定して再構成しました。鮮色はデータマークに限定し、小さな色文字には同系の濃色を使います。歴史顔料の科学的復元を称するものではありません。

三つの言語版は同じデータ、尺度、図形の幾何、カラートークンを共有します。チャート名、問い、軸ラベル、凡例、アクセシビリティ用タイトルと説明は言語別にローカライズされています。

## 基本原則

1. 図形を選ぶ前に、読者が比較すべき関係を決める。
2. 単系列の基本色はベロ藍とし、鮮朱は焦点、異常、リスクに限定する。
3. 色だけで情報を符号化しない。線種、白抜き・塗りのマーカー、輪郭、順序、直接ラベルを併用する。
4. 標準的な棒グラフはゼロ起点とし、装飾で長さ、面積、線幅、位置、角度を変えない。
5. 金は画面の継ぎ目と見出しを整理する色であり、プロット領域を覆う色ではない。
