# Kinpeki Ukiyo Chart Vocabulary

A contemporary chart system for journalism, research, teaching, and business analysis. Kano-school kinpeki screen composition informs the spatial rhythm; ukiyo-e woodblock keylines, flat colour separation, and oblique cropping inform the graphic language; modern data-visualisation rules govern scales, labels, units, and accessibility.

This is a contemporary synthesis. It does not claim that “Kano ukiyo-e” was a single historical school, and it is not endorsed by any museum or cultural institution.

The public edition uses a new-impression high-chroma rule. The museum reference image remains unaltered; chart colours are rebuilt to evoke a fresh print. Vivid roots are reserved for data marks, while small coloured text uses darker tonal partners. This is not a scientific reconstruction of historical pigments.

## Contents

- 9 information-relationship families
- 67 editable standalone SVG charts in each of Chinese, English, and Japanese; 201 files in total
- One 2400px-wide vocabulary poster for each language
- Independent responsive pages and 390px mobile treatments for all three languages
- A complete-print reference section for Hokusai's *The Great Wave*
- Palette tokens, chart-selection guidance, colour rules, and a style-translation guide

## Languages

- Chinese: `index.html`
- English: `index-en.html`
- Japanese: `index-ja.html`

All editions share the same data, scales, geometry, and colour tokens. Chart names, questions, axis text, legends, accessibility titles, and descriptions are localised for each language.

## Core rules

1. Choose the relationship before choosing the form.
2. Use Prussian blue for a default single series; reserve vivid vermilion for a focal value, anomaly, or risk.
3. Never rely on colour alone. Add line styles, open/filled markers, keylines, ordering, or direct labels.
4. Start standard magnitude bars at zero. Decoration must never alter length, area, width, position, or angle.
5. Gold organises screen seams and headings; it does not fill the plot area.
